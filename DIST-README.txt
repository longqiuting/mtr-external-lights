MTR external lights（MTR外部光源）— 多版本测试包说明
==================================================

每个 jar 对应一个 Minecraft 版本，文件名末尾就是对应版本号：

    mtr-headlight-0.1.0+1.20.1.jar
    mtr-headlight-0.1.0+1.19.4.jar
    mtr-headlight-0.1.0+1.19.2.jar
    mtr-headlight-0.1.0+1.18.2.jar

环境要求（Fabric）
------------------
| MC      | MTR              | LambDynamicLights        | Mod Menu（可选）      |
|---------|------------------|--------------------------|-----------------------|
| 1.20.1  | 3.6.4.2          | 4.4.0+1.20.1             | 7.2.2                 |
| 1.19.4  | 3.2.2-hotfix-1   | 2.3.1+1.19.4             | 6.3.1                 |
| 1.19.2  | 3.2.2-hotfix-1   | 2.2.0+1.19.2             | 4.2.0-beta.2          |
| 1.18.2  | 3.2.2-hotfix-1   | 2.1.0+1.17               | 3.2.5                 |

Fabric API 用对应 MC 版本的最新版即可（1.20.1 用 0.92.12+1.20.1，1.19.4 用 0.87.2+1.19.4，
1.19.x 用 0.77.0+1.19.x，1.18.2 用 0.77.0+1.18.2）。

配置文件
--------
    config/mtr-headlight.json

改过默认值后想回到新的默认值，直接删掉这个文件即可（会自动重建）。

打开配置界面
------------
- 聊天栏输入 /externallights（会提示“MTR-headlights模组：指令执行成功”并打开界面）
- 或：模组菜单 → MTR Headlight → 配置

界面里有：总开关、动态光源渲染距离滑块（含“同步到游戏渲染距离”）、车厂/侧线过滤、
立即重载所有列车动态光源。

各版本差异（重要）
------------------
1.20.1：车灯是真正的“线光源”，光束连续均匀。

1.19.4 / 1.19.2 / 1.18.2：LambDynamicLights 2.x 只有“点光源”接口，所以光束是用沿光束均匀
分布的 8 个点光源近似出来的。观感上：隧道/地面的照亮效果接近，但贴近看时明暗过渡会比
1.20.1 略粗糙一点，这是光照引擎的限制，不是配置问题。

光影（Iris / OptiFine，1.20.1）
------------------------------
- 车灯烘焙进轨道模型的那份顶点光照在光影下正常工作（MakeUp、Bloop、Cyanide 均已验证）。
  之前“开光影轨道不亮”的根因是本模组自己的 mixin 插件用 `Class.forName` 提前装载了 ANTE 的类，
  导致其它模组的 mixin 无法注入；已改为资源路径探测，**光影下烘焙光正常显示**。
- 因此原先的兜底方案（自绘光带 / `railGlow*` 系列配置）已整体删除，光影内外都只有一份
  烘焙进轨道的动态光，不存在两套效果叠加的问题。
  **（2026-11 更新）** 自绘光带的能力已恢复，但**默认关闭**：`config/mtr-headlight.json` 里
  `railGlow: true` 才会绘制，光影内外都不会自动接管，与烘焙光的重建调度完全独立。
  宽/透明度/抬升/前伸长度/采样步长分别用 `railGlowWidth`(1.2) / `railGlowAlpha`(0.12) /
  `railGlowLift`(0.07) / `railGlowAhead`(14) / `railGlowStep`(1.5) 调。
- `railLightShaderBoost` 现在**默认关闭**。它把亮度也写进顶点光照的天空通道——理由本身仍然成立
  （天空通道为 0 时部分光影包会把 candle 项砍半），但当初触发它的主要现象其实是上面那个类装载
  bug。若某个包下轨道仍偏暗，直接在 `config/mtr-headlight.json` 里把它设为 `true`
  （界面已精简为「总开关 + 侧线配置」，其余参数只在配置文件里）。

已知边界
--------
- 只照亮方块（地面、隧道壁、站台）。MTR 的列车车体和 ANTE 的立体轨道使用自发光渲染，
  不经过方块光照，任何动态光源都照不到，改动它们需要 mixin 进 MTR/ANTE，因此不做。
- 1.18.2 / 1.19.x 为编译验证，尚未实机跑过；重点看：多车是否都有光、发车时前车灯是否
  稳定、/externallights 能否打开、侧线过滤是否生效。
- 日志若有 [mtr-headlight] 开头的报错，把 logs/latest.log 发给作者即可。
