**本版重点：车灯从“照亮轨道”改为“车灯发出的光束”**

### 新功能
- 车灯光束：沿车头三维朝向直线投射（不随轨道弯曲）、贴地、3 格宽，横向与纵向渐淡
- 车头/车尾的长度、颜色、高度可分别配置；默认暖白 16 格、淡红 4 格
- 逐车厢几何：弯道时车头/车尾灯各自贴合所在车厢的切线方向
- 配置界面重做：全局 + 按侧线覆盖（三层开关：总开关 / 动态光源 / 光带）
- 侧线列表支持按车厂分组与搜索
- 颜色支持色块选择与自定义十六进制

### 修复
- 列车停在车厂（未发车）时不再发光
- 1.19.4 光带因矩阵未上传而完全不可见
- 1.18.2/1.19.2 动态光源在区块边界断带
- 1.18.2/1.19.2/1.19.4 新增 NTE 轨道动态光照（此前只有 1.20.1 的 ANTE 有此能力）
