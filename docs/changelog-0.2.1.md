**本版为 0.2.0 的补全与打磨，四个版本功能对齐**

### 新增
- 侧线选择支持**地图视图**：俯视 2D 图绘制车厂矩形与侧线（含两端连线），悬停高亮显示编号/长度/节数/状态，点击进入该侧线详情；滚轮围绕光标缩放（最大 8x）、拖拽平移、重置视图、北向标记
- 每一项配置旁新增 **↺ 恢复默认**；底部新增 **全部恢复默认**（带确认屏）
  - 全局页的 ↺ 恢复该字段的默认值
  - 侧线详情页的 ↺ 是清除该项覆盖、重新跟随全局

### 修复 / 优化
- **轨道加载变慢**：进世界后 8 秒完全让路、距离 64 格 + 视野过滤、同 chunk 冷却 500ms、全局每秒 12 次配额。旧版 4 列车同屏约 65 次/秒（占满 ANTE 的构建队列），现在降到约 6 次/秒
- 上述参数全部可在配置文件中调整，部分支持按侧线覆盖

### 说明
- 地图与恢复默认在 1.18.2 / 1.19.2 / 1.19.4 上完成了移植，仅为 API 适配（`MatrixStack`、`ButtonWidget.EMPTY`、`Text.of` 等），行为与 1.20.1 一致
- 三个旧版本本版仅做了编译与静态核对，实机验证请以你自己的测试为准
